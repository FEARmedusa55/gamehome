Installing the game

  1. Open InstallerX Revived

  2. Go to Available Privileges

  3. Switch from Shizuku to No Privilege

  4. Go to the downloaded .apks file and click on it

  5. You should be prompted what to open this file with, select InstallerX Revived -> Choose either Just once or Always

  6. If InstallerX Revived asks you to allow notifications, allow them.

  7. Click on Select Package

  8. Under Feature Splits choose which episode you'd want installed alongside the base game, or leave all selected, then click Next

  9. Click Install

  10. When the package installer prompts you to install the game, click Install

  11. If a Unsafe app blocked warning shows up, click on Install anyway
    - For some users, the Install anyway button may be hidden behind a More details button!

  12. Start up the game and enjoy!
