Installing the game

  1. Open ZArchiver

  2. Find where you saved the APK you downloaded (likely in the "Downloads" folder)

  3. Tap on the file, then tap Install

  4. When the package installer prompts you to install the game, click Install

  5. If a Unsafe app blocked warning shows up, click on Install anyway
    - For some users, the Install anyway button may be hidden behind a More details button!

  6. You should see a toast message below saying App installed once it is successfully installed.

  7. Start up the game and enjoy!
