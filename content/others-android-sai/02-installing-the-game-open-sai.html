Installing the game

  1. Open SAI

  2. Go to Select file(s)

  3. Select the System file picker

  4. Accept the increased storage use warning by clicking OK, then go into the folder you downloaded your bundle to

  5. Select your bundle, ignore the File is too big to copy warning, if you get it, and click Install

  6. Wait for your installation to finish

  7. When the package installer prompts you to install the game, click Install

  8. If a Unsafe app blocked warning shows up, click on Install anyway
    - For some users, the Install anyway button may be hidden behind a More details button!

  9. Start up the game and enjoy!
