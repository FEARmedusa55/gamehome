If you have an Apple TV with this game installed, please contact one of the owners with the contact info linked in the Credits page.

The Apple TV version is an incredible oddity. Being exclusively 32-bit and (supposedly) never having episodes 6-8 released on it, it's by far the most obscure version of Minecraft Story Mode. Because of its incredibly small support window, only Apple TVs 3/4 running TVOS 7.1 - 10.3.3 can run the game. Because of this, along with its (understandably) extremely low sales, it has never been dumped. The performance of this version is more or less unknown, as there are no high quality recordings of it.


Even though no one will realistically play it, ripping the game would still help a lot in archiving this game's history. While we're here, it might be worth talking about FireTV as well. There was a FireTV release, although FireTV OS is just based off FireOS, which is based off Android, so you'd be fine installing the Android package and hooking up a controller.

Also, for some reason the game will get stuck at the title screen if you're logged into iCloud.
