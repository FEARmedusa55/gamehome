Homebrew

You need a jailbreakable PS4. You must to be on firmware 13.00 or lower. (As of August 2025.) ConsoleMods has a detailed thread for all jailbreakable firmwares that's regularly updated.


If the thread recommends you update to a newer firmware, you need to install an update via USB. PS4 firmware update files can be obtained here.

The best place to get a pkg is dlpsgame. Download link here.
PKGs are easily installable via the GoldHEN Package Installer menu, but you probably know that already if you have a modded PS4.


While MCSM was never released on the Vita (although it was (supposedly) planned to release alongside the Wii U version), it's worth mentioning that MCSM is playable on the system via remote play with an internet connection and a PS4 system.
