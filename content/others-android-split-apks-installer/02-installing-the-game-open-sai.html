Installing the game

  1. Open SAI

  2. Go to Install APKs

  3. Select either the Internal file picker or the System file picker

  4. Go into the folder you downloaded your bundle to

  5. Select your bundle, then click Select

  6. Wait for your installation options to pop up, alternatively disable episodes you don't want from the installation and click Install

  7. When the package installer prompts you to install the game, click Install

  8. If a Unsafe app blocked warning shows up, click on Install anyway
    - For some users, the Install anyway button may be hidden behind a More details button!

  9. Start up the game and enjoy!
