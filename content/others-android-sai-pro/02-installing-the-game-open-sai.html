Installing the game

  1. Open SAI

  2. Go to Select file(s)

  3. Select either the Automatic search or the System file picker

  4. Depending on what you chose, follow the bullet point below:
    - For Automatic search, choose the bundle that was found automatically from your Download folder
      - Wait for your installation options to pop up, alternatively disable episodes you don't want from the installation and click Install
    - For System file picker, go into the folder you downloaded your bundle to and select your bundle
      - Wait for your installation options to pop up, alternatively disable episodes you don't want from the installation and click Install

  5. Wait for your installation to finish

  6. When the package installer prompts you to install the game, click Install

  7. If a Unsafe app blocked warning shows up, click on Install anyway
    - For some users, the Install anyway button may be hidden behind a More details button!

  8. Start up the game and enjoy!
