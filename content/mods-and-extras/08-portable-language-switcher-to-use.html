Portable language switcher
To use it, close the game, add the file in the root folder of the game's install.
LanguageSwitcher32.exe = MCSM Season One
LanguageSwitcher64.exe = MCSM Season Two
Run LanguageSwitcher -> Hit Browse... -> Select GameApp.exe -> Select the game's UI language you desire -> Hit Save
This creates a shortcut file named after GameApp.exe with your language; Feel free to put that shortcut wherever you want, launch the game from that shortcut for the language to be used.

  • Has been forked from https://github.com/InWILL/Locale_Remulator and modified to be as simple and portable as possible.

Has not been tested with Season Two yet.
